# 拿破仑1803反事实全景推演 · 根节点研究设计 v2（r_b55f2c1cf5 / 深度0）

## 原始问题
回到1803年，拿破仑如何才能逆转历史，赢得战争胜利，让法国成功控制整个欧洲并建立长久的法国霸权主导秩序？一个法国胜利的欧洲19世纪上半叶新秩序会如何运作，英国的海上优势（英法海军差距）会逐步缩减到什么程度？西班牙在拿破仑安排下最终变成共和国、波旁立宪君主还是波拿巴立宪君主？拿破仑是否有意愿和能力支持罗马王统一中南意大利，还是更愿意意大利邦国林立？德意志邦国中普鲁士还会比奥地利更强势吗？拿破仑是否有意愿和能力协助西班牙盟友维护美洲殖民地，法国介入下拉美格局如何变化？拿破仑对收回七年战争失去的法属印度乃至夺取英属印度有无意愿，如有需要怎么做？要求：历史推演报告，每一处细节皆有来源，不得臆想。

## v2修订说明
v1把"如何赢得战争"压缩为一张节点清单卡、把"新秩序如何运作"压缩为一张综合卡，承重不足。v2将主问拆为两个任务簇：
- **胜利路径簇**（如何逆转、赢得战争、控制欧洲）：C1全景地图 + C11入侵英国 + C12俄国问题 + C13和约落锁 + C14陆军可持续性 + C2/C3/C4物质基座 + C17路径总装。
- **秩序运行簇**（新秩序如何运作、能否长久）：C8政治-正统性核心 + C15大陆经济秩序 + C16英国与世界体系 + C9霸权财政 + C10制度移植因果证据 + C5/C6/C7/C18区域支柱。

## 研究目标
产出**分层标注证据**的历史推演报告：(1) 文献可证的分岔点与2–3条经约束校验的完整胜利路径（含概率带与"奇迹计数"）；(2) 明确情景下"法国胜利的欧洲"的运作模型（政制、经济、财政、军事、教俗、王朝、边疆）；(3) 八个子问题各给证据加权的分支结论；(4) 学派分歧并列，证据不能裁决处不强行裁决。

## 待检验的假设（皆为问题）
- P1 「失败源于可避免的决策错误」vs 结构不可能论（Schroeder）/俄国韧性论（Lieven）/财政海权决定论（Crouzet/O'Brien）。
- P2 「控制整个欧洲」是连贯目标还是滚动机会主义（Esdaile）？
- P3 海军差距是可缩减的数量还是制度性质量鸿沟（军官团断层、封锁训练陷阱）？
- P4 西班牙必然走向立宪安排吗？1808年桌面上到底有哪些选项？
- P5 「罗马王」=意大利统一选项，还是罗马作为帝国第二城的法兰西工程？
- P6 普奥消长是双极问题，还是法国秩序同时压制两者、扶植第三德意志？
- P7 拿破仑承诺不可信问题：长久秩序需要的承诺技术与"拿破仑仍是拿破仑"是否相容？
- P8 「胜利」必须击败英国，还是存在"英国不败但接受法制欧洲"的共存均衡？
- P9 入侵英国即使登陆成功是否等于战争结束？（舰队在外+海外帝国续战机制）
- P10 俄国问题有解吗：任何让步包下亚历山大是否都会摊牌？
- P11 贡赋帝国能否和平转型为税收-信用国家而不动摇政权阶级基础？

## 边界与操作化定义
- PoD窗口：≥1803年5月；路易斯安那出售与圣多明各败局视为既成（C1可考据翻案窗口但不作主干）。
- 视野：秩序运行推至约1848；海军/财政量化轨迹推至1830。
- 「控制欧洲」按大帝国范畴操作化：并合省/征服国/藩属王国/强制同盟四层；「长久」=拿破仑合理寿限+至少一次继承（至1830–40年代），分层作答（在世/摄政期/第二代）。
- 海军差距度量：战列舰与巡航舰存量及年下水、在役海员与海上训练日、预算、军官经验结构、护航投送能力；差距结论分"吨位差距"与"效能差距"两条线。
- 证据分层标签（全项目强制）：【事实】【文献推断】（注明谁）【模型推演】（显式假设）【裁量】（+置信度）。禁止无标签断言。
- 引用诚信：只引实际读到的版本；仅经二手知道的档案标"转引自X"；圣赫勒拿材料（Las Cases、Gourgaud、Bertrand、O'Meara）一律标"回溯性"；意图主张优先用1815年前文书。档案系列名（AN AF IV、SHD GR C/MV BB4、AAE CP、TNA ADM/FO/WO、AHN Estado、AGI/PARES、HHStA、GStA PK、AGAD华沙）作为出处谱系列明，不假装读过未见的原折。

## 方法论契约（各卡共用）
1. 最小改写：每个分岔须是文献可证的当时桌面选项（通信、备忘录、参谋计划、同时代提案）或当时实际发生过的同类外生事件；来源必载。
2. 二阶效应纪律：后果推演锚定真实记录中的机制类比（荷兰路易1810退位=封锁执行逼反藩属；1809蒂罗尔=征兵-宗教反弹；华沙公国=藩属过载）。
3. 反事实质量标准：Tetlock & Belkin五准则+Ferguson导言（只采纳同时代人实际考虑过的替代）+Evans《Altered Pasts》警戒；C1产出一页方法基准附录作全项目量尺；C17负责把"选项"变"路径"时逐格校验资源冲突与时滞。
4. 学派并列：Schroeder体系论｜Broers/Grab现代化帝国论｜Esdaile赌徒论｜Crouzet/O'Brien财政海权结构论｜Lieven俄国韧性论｜Bayly/Mikaberidze全球史观｜Sorel自然疆界结构论（与Schroeder对撞）｜Planert德意志民族主义祛魅｜Rodríguez O./Guerra拉美正统性危机论。结论标明在哪个学派前提下成立。

## 共用情景框架
- S0 史实基线（校准）。
- S1 不列颠中立化：1803–05入侵成功或迫和（C11判定概率与"登陆≠终战"问题）。
- S2 大陆整固：提尔西特后不废西班牙王、不打俄国；英国不败→武装共存/消耗战（C12判定俄国问题是否有解）。
- S3 封锁绞杀：S2+体系强化执行→以1810–11英国危机为杠杆谋谈判和平（C4/C16判定英国何时、是否媾和；直面伊比利亚执行悖论）。
- S4 东方转向：S2+法俄共管向奥斯曼/印度（C7/C12判定其内在破裂点）。
- S5 王朝固化：S1–S3任一+继承落地→1815–48运行期（C8/C9/C15/C16/C18+区域卡）。
分支概率用高/中/低+理由，不做伪精确；C17输出各路径奇迹计数。
