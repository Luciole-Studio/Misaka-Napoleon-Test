### 声明2｜B 层的否定理由升级为"被 C 层支配"（claim_type: inference）

→ 法国能给客户政权的东西，海地现政权已经拥有；法国额外能给的只有承认与市场准入——**而这正是 C 层无需扶立政权即可给的**。
→ **B 层在结构上被 C 层支配（dominated）**：凡 B 能实现的目标 C 都能以更低代价实现，而 B 额外承担"扭转一个无根政权的存活"这项成本 C 不承担。**概率带 0.12–0.30 不改，但理由从"可信度低"升级为"被支配"——后者是更强的否定。**

## §25　提交后勘误：矩阵编码不一致与识别力限制（应 Q1 10036 复审）

来源：10036 于本卡提交后发来的识别/口径审查（其声明未读到 §21–§23，故所评为消息内容）。本节逐条核对后写入。**卡已 done，`misaka_card_note` 不再受理（返回 ownership changed），故勘误存于此处，审阅者请与 §23、§24 并读。**

### ①【重要勘误】2格不是3格，而且 §22 与 §23 对同一案例的 P₂ 编码互相矛盾

10036 指出：三个案例只占两格、且全在 P₂ 有接管者一列，右列全空。**核对属实**——§23① 的标题「四格中的三格现已有实测」与其下方表格自相矛盾，表内只有两格有观测（左上：那不勒斯全王国1806–15；左下：圣多明各1808–09＋帕特诺珈1799），右列两格均标「未观测/预测」。标题作废。

**但更严重的是 10036 未及见的一层：同一个南意战区在两节里被编了相反的 P₂。**

| | §22 原矩阵 | §23 重编后 |
|---|---|---|
|南意/那不勒斯战区|卡拉布里亚1806–11 编为 **P₂ 无**（英军赢马伊达却撤回西西里，波旁宫廷无英国刀剑即不能守大陆）|那不勒斯全王国1806–15 编为 **P₂ 有**（巴勒摩波旁有正统索赔＋英国刀剑＋masse 网络）|

两种编码不能同时成立。而§22 的核心命题「更小的承诺→更快的全损，其充分条件是 P₂ 成立」**正是靠这一对反差识别的**：卡拉布里亚（P₂无→消耗）vs 圣多明各（P₂有→全损）。§23 把南意改编为 P₂ 有之后，**该对反差消失、右列清空，P₂ 不再有变异**，命题却被原样保留并在 §23②–③ 上又加盖了更强的推论。这是典型的**把结局写进解释变量**：那不勒斯没有快速全损，于是把它的 P₂ 读为「有但拉锄战」；圣多明各快速全损，于是把 P₂ 读为「有且即刻接管」。

**更正**：
1. §23① 标题改为「四格中的**两格**现有实测，且均在 P₂ 有接管者一列」。
2. P₂ **必须改用事前可观察的接管资源编码**（是否存在携正统名义、拥有自有武装与财源、且能到达现场的索赔政权），而不是事后的「是否真的接管并守住」。按事前口径，巴勒摩波旁与 Sánchez Ramírez 都应编为 P₂ 有，**则 §22 的原对反差自动作废**，当前材料内 P₂ 无任何变异。
3. P₁ 同理需固定观察时点（接管发生前一年），不得用 1806–15 累积形成的缪拉国家机器去解释 1806 年的存续。

### ②【降格】两条超出识别力的命题

- 「P₂ 是少投入→快崩溃的**充分条件**」→ 降为**条件机制假说**，标明当前材料不能检验（无 P₂ 变异）。
- 「客户政权的存活概率等于宗主国而非治理绩效」（§23③）→ 降为假说。同地形异结局只推翻了**地形的单因素充分解释**，不排除地形的条件作用；这一点 10036 正确，本卡接受。
- **缪拉案的反例核查（本卡自补）**：§23③ 把 1814–15 写成「帝国塌→托伦蒂诺→移交」的单链，**略去了缪拉 1814 年转盟、即曾主动试图脱钩于担保人，及 1815 年是他自己开战而败**。修正后的读法：客户政权**即使转盟也未能脱钩**，因为决定其存废的是欧洲正统档而非当地绩效——方向与原推论一致，**但机制不是「担保人崩溃自动传导」，不得再以单链陈述**。

### ③【采纳】观察单元不得合并

§23③ 把「海地无外部索赔者」推出「全损且无残值」。按 10036 的区分，这里混了两个变量：**无外部接收者**（无回归的旧宗主）与**无本地继承政权与制度残留**。海地恰恰**有**一个强有力的本地继承国家去吸收法式客户政权——这才是「无残值」的真正原因，与那不勒斯的「换旗留任」形成对照的是**接收者的性质**而非有无。另：海地（1804–）与东部圣多明各1808–09 **不得合为同一观察单元**，二者在人口、政权类型、外部支持上均不同。

### ④【采纳】「不登陆＝0」的适用范围

§24⑤ 已限定为「当地常驻岗位为零」；再加一层：它**只是该战区的陆军驻屯成本**，不包含海军己令、分舰队维持、外交与外交赍偿（如 1825 式承认代价）等总体政策成本。

## 声明16｜甜菜糖数字更正（X3 警报 → Last Order 在 Heckscher 印 pp.292–293 原文核实；总装口径，HT 正文不重开）（claim_type: fact）

HT §10 与年表 #13 的「1813 年 334 家厂产甜菜糖 3,500 吨」系 **Montalivet 1813-02 向立法团的展望值**（7,000,000 livres ≈ 3,500,000 kg），非实产。Heckscher 印 pp.292–293 载同年后期 Montalivet 致皇帝报告：因技术无知与恶劣天气，**实产仅 1,100,000 kg，334 张执照中仅 158 张实际使用**；复辟后工商总监称品质极差，帝国崩溃后无一厂存活。

→ 因此 HT 的换算「3,500 ÷ 95,045 = 3.7%（占 1788 法属殖民糖产量之比）」应更正为 **1,100 ÷ 95,045 ≈ 1.2%**。
