# models/navy　海军差距重算（第五版第三章，R2b，2026-09-26）

**性质：条件算例。**所有输出都是"在这组假设下会怎样"，不是历史预测，也不是统计置信区间。代码只用Python标准库。

## 一、为什么重算
旧稿第三章（快照 `02b_英国海权与和平_舰队海峡与帝国.md` 第195行）给出的"1830年约相当于英国一半至三分之二的年度可动员主力舰吨位"是作者选定的规划目标，没有用第一章的海军预算重跑舰队模型；英国的反应只作为一行敏感性（P4：0.876→0.731）。本目录把三件事接进同一个模型：
1. **法国预算耦合**：第一章750档海军1.45亿法郎（1815—29）、850档1.65亿（1830—48）；先付固定项、在役舰、储备舰，余额才能造新舰；造舰还受船台—木材产能上限和"不造配不上人的舰"两道约束。
2. **英国反应内生**：沿用旧稿第241—248行与B3/P4第5节的规则——战时在役舰≥r·F＋g；和平时一年内可动员舰≥r·F＋g，舰体≥可动员目标/a；F是法国（及盟国、俄国按权重）可集中的战列舰。英国受造舰速度（≤8艘/年，缺口大时≤12艘）与议会费用上限约束。
3. **三条轨道**（与 `audit/20260925_复审与修缮/P2_三轨道设定.md` 一致）：最可能（甲）、昙花一现、强行成功（乙、丙），各有1810年起点、预算、停战年、海员来源、港口得失与安特卫普分支。时点延到1848年。

## 四、校准锚点（出处见第三章注释）
**法国**
- 实支：共和十二年1.80亿、十三年1.40亿、1806—1810年1.05—1.10亿、1811年1.55亿、1812年1.59亿、1813年1.67亿（Marion IV，页325）；1816年预算0.48亿（页399—400）。
- 1810年7—10月方案：两三年造60艘、总数约110艘；1810年43艘中37艘武装；预计每年约2亿；1812年造修评估2.234亿、1813年2.557亿、1814年维持评估1.459亿、1812年预算削至1.9亿（Todorov 2008，页3—5、注116）。
- 1819年海军部声明：年支出限于4,500万，1830年海军将不复存在；年支6,500万，1830年余38艘战列舰、50艘巡防舰（Paixhans 1822，页342；影像核对为"50"，P4卡笔记误作30）。
- 波塔尔方案：40艘战列舰＋50艘巡防舰，十年，年6,500万（含殖民地600万）（WarHistory.org网文，线索级）。
- 由此：和平固定项（小法国）约2,800万；反事实帝国40（34—46）百万；在役舰（和平）0.9（0.8—1.0）百万/舰年；储备舰0.30（0.25—0.35）；造一艘战列舰2.3（2.0—2.6）；巡航舰附加κ和平0.4、战时0.3。战时1811—13年：固定项52（45—60）、在役1.3（1.15—1.45）——比拿破仑1814年维持评估高约15%，评估本身偏乐观（1812年评估2.234亿，实支1.59亿）。
- 海事登记：1825年94,611人，1845年125,272人（Villiers & Culerrier 1982，页52）；1835年检阅：登记90,000人，合格、适龄且可调者35,000人（39%），其中18,000人已在王家海军（图皮尼耶报告，经1839年3月4日下院辩论转述）。模型和平年A12另受 (0.39×登记数×轨道范围系数×和平贸易增长 − 非战列舰合格员)/450 的上限约束。

**英国**
- 1810年海勤战列舰124艘、在役108艘（James年表，B3）；1812年145,000人、拨款£19.306m（Fremont-Barnes p.44）。
- 实支（Porter《Progress of the Nation》页505—506）：1817—30年£5.0—6.5m；1835—38年£4.1—4.8m；1846—48年£7.8—8.0m。
- 员额：1817年19,000，1820年23,000，1824年29,000，1830年29,000；1835年17,500，1836年22,500（Hansard）。在役战列舰：1817年15、1823年12、1832年11、1835年11、1837年20；1839年物料足供50—60艘战列舰出海（Hansard 1839-03-04）。
- **规则的史实检验**：1838—39年法国约22艘浮存（8—10艘在海）、俄国约43艘浮存；以基准参数（r=1.12，c_F=0.85，g=20，俄国权重0.5，法国A12约20、俄国约35）计算，英国应保有约59艘可动员战列舰，与1839年海军部所称"物料足供五六十艘"相当。
- 费用：K0 £1.8m、每舰年£0.02m、每人年£80（和平）/£100（战时）、每造一舰£0.09m；1820年验算约£6.0m（H≈100、在役15、造2艘；实支£6.34m）；战时在役90—105艘时约£16.7—18.4m（1810—12年实拨£19—20m，含运输与俘虏等项）。议会和平上限£9/12/15m（B3武装和平包）。

**分解（最可能轨道，1830/1848年TA）**：英国反应关闭（只保和平下限）→1.48/1.83；英国强反应→0.59/0.63；英国弱反应（议会上限£9m）→0.85/0.91；法国参数不利→0.60/0.67；有利→0.76/0.80；安特卫普不受限→0.66/0.72（法国产能不受约束，英国却多留北海分舰队）；战时预算只有第一章650档的90百万→1815年0.35，1830年0.67；乙层把和平预算提到1.95亿（陆军280→230）→比值不变（海员封顶）。

## 六、已知局限
1. 法国人员流量沿用F3，可能偏乐观；以海事登记上限作外部核对后，最可能轨道的上限大体不紧。
2. 战时成本比拿破仑1814年评估高约15%；1811—13年的实际下水（最小清单每年7—9艘）与模型160百万时8.6—9.5艘相符。
3. 1848年仍以帆装战列舰计；蒸汽只做"预算15%转蒸汽"敏感性（最可能轨道1848年舰体151→129，A12 111→109）。英国在机器、煤站与商用汽船上的领先在正文中作定性修正。
4. 西班牙、荷兰、俄国舰队只是按权重计入英国的威胁估计，没有独立的造修模型。
5. 训练质量不再乘系数（A12已含合格海员约束）；P4的训练系数只在正文注释中作诊断。
