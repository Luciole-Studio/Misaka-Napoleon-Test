# P2-D　动态行省化模型（v3.1，2026-09-26）

## 为什么要换掉原来的静态模型
原P2模型（研究卡 t_c98c24，`p2_joint_model.py`）把若干张地图的人口、驻军密度、宪兵密度、征兵与税余分别相加，比较"所需在场兵力"与"可支付兵力"。它有三处结构性限制：
1. 驻军需求只随人口线性增长，不随整合阶段下降，也不随抵抗强度变化；因此"并得越多越亏"几乎是构造结果。
2. 没有时间维度：新省从占领到例行化需要多少年、各阶段需要多少人与钱，都没有进入计算。
3. 政策与冲击没有进入因果链：征兵强度、教会冲突、市场排斥、债务处置、战争与歉收、继承危机，只作为文字说明存在。

P2-D保留P2的地区参数（人口、省数、驻军与宪兵密度区间、征兵、本地官员比例、税余区间），在其上加入时间、阶段、抵抗与冲击，用来推演三条轨道在1803—1848年的逐年走势与断点。它是**条件算例**，不是历史预测，也不产生概率。

## 结构
### 单位
- 地区 r（约25个，见 `regions.csv`），年份 t（1803—1848）。
- 控制层 L ∈ {无, C 同盟, B 法典化藩属, A 并合省}。
- 整合阶段 S ∈ {0 占领, 1 行政并合, 2 功能整合, 3 政治整合}（只对A层和B层内部改革有意义）。
- 抵抗指数 R ∈ [0,1]（潜变量；由政策、结构条件与冲击决定，经适应逐年回落）。

### 抵抗的动态
R(t+1) = R(t) + a·[R*(t) − R(t)] + 冲击(t)

R*（均衡抵抗）＝ 结构底值（语言距离、既有自治传统、教会组织强度、外援可达性）
　＋ 政策负担项（征兵强度相对该地可承受水平、税负上升速度、教会冲突、市场排斥、债务削减）
　− 收编项（本地精英任职比例、市场平等准入、双语司法、宗教和解、代表权）
　− 适应项（随并合年数递减，上限由研究卡Q2的L/M/H三种剖面给定）。

a（调整速度）按Q2剖面校准：低摩擦地区3—6年进入例行化，中摩擦6—12年，高压地区单靠时间不回落。

### 驻军需求
v3起驻军密度为 g = 1.5 + 25·R²·(0.35 + 0.65·O) + 边境常备（每千人），其中O是"外部军事机会"（0—1，按研究卡Q1的编码）：外敌军队够不到的地方，抵抗主要表现为逃役、少交税，而不需要成倍的驻军。战区（W层）取O＝1。逃役与实收仍用完整的R，另加"消极抵抗"项（罗马0.375，托斯卡纳、伊利里亚0.10），只进入逃役与实收。

### 供给
- 新兵：人口 × 征额（每千人）× 到营率(R,S) × 可靠系数(S)，按五年役期形成存量（沿用Q2假设，并修正原P2函数第五年即封顶的问题）。
- 税：人均可征额 × 实收率(R,S) − 地方行政与旧债 − 征收成本；以马里翁1812年各区预期毛额与高丹1811年增收预期为上限锚，以D2"财政实情"栏为下限提示。
- 干部：每省高级职位约10个、带薪文官约160个（P2口径）；外派比例随本地培养逐年下降；法国可外派干部总池以参政院审计官（1813年约452人）、宪兵（1809年实数15,474，1811年编制26,000）等为锚设定年增量。

### 全国约束
- 陆军预算与兵均成本（第一章：700—900法郎；3亿—3.5亿法郎陆军档）。
- 盟军自养兵力（按条约兵额×到场系数）；某地一旦由B层转为A层，其原有自养军就不能再算作盟军（原P2已有此规则）。
- 海军与其他任务不重复计入。

### 冲击日程（按轨道设定）
战争（1805、1806—07、1809、1812—14等，依轨道而定）；伊比利亚战争（仅在废王分支）；教会冲突（1809—14，仅在并吞罗马分支）；1811—12年粮荒；1816—17年坦博拉饥荒（外生，各轨道都有；储备政策只能出于1811—12年粮荒后的当时理由）；皇帝死亡的窗口（外生，按健康史设区间）；1820、1830、1848年的革命浪潮（外生部分＋内生部分）。

### 断点判定
地区层：R连续两年超过阈值且驻军缺口不能补足→该地区"脱离"（降为B或C，或落入敌方）。
全国层：驻军缺口、预算缺口、干部缺口三项压力之和超过阈值，同时遇到外部冲击→外圈连锁脱离。

## 三条轨道的设定（与书稿第三部对应）
1. **最可能（甲层）**：1807年后停止扩张；并合限于帕尔马、托斯卡纳（有条件）、瓦莱；其余保留B、C层。
2. **昙花一现**：史实并合日程照走（荷兰、汉萨、奥尔登堡、罗马、伊利里亚、加泰罗尼亚），1812年对俄以有限战争收场（奇迹登记），1813年以后继续并合（威斯特法利亚、贝格、埃布罗以北等，按当时已有的动议）；西班牙战争与英法战争延续；1816年饥荒；皇帝死亡窗口到来后进入继承危机。
3. **强行成功（乙、丙层）**：当时最好的方案组合（宗教和解、市场平等、保全债权、双语司法、本地精英任官、较轻征兵、关税同盟）＋登记在案的运气；丙层再加大直辖范围与奇迹假设。

## 文件
- `regions.csv`：地区参数（v3按第十章起草人的史实校准修订，新增 `O_base`、`passive_w` 两列）
- `p2d_model.py`：模拟程序与轨道设定（Python标准库）
- `variants.py`：去掉一个条件、换统治方法、英法战争延续等变体
- 输出：`out_<轨道>_yearly.csv`、`out_events.csv`、`out_sensitivity.csv`（`--sens`）、`out_region_yearly.csv`（`--regionlog`）、`out_variants.csv`
- `archive_v2/`：v2（2026-09-26 00:34版）的代码、参数与全部输出，供对照

## v3校准（2026-09-26）
依据第十章起草人交稿说明第七节（Joor 2009、Aaslestad、Grab、Madelin、Broers、Woolf、Rowe，经研究卡D1、D2、Q1转引或直读）：
1. **驻军按外部军事机会折减**（见上）。各地区的结构性O：荷兰、汉萨、罗马、托斯卡纳0.05；瓦莱、帕尔马0；伊利里亚、北意、南德、华沙0.3；那不勒斯0.8（西西里）；西班牙各区1。史实轨道另设1809年（奥地利战争、瓦尔赫伦登陆）与1813年（联军逼近）两次事件。
2. **消极抵抗通道**（`passive_w`）：罗马的宣誓、圣事、告发三重罢工只压低到营与实收，不引发大规模起义（Q1把RM1809编为mass＝0）。
3. **参数修订**：荷兰R0 0.35→0.20、征额1.8→2.5、征兵承受1.5→1.0、宗教0.05→0.03、市场0.30→0.20、外援0.15→0.05；汉萨R0→0.12；托斯卡纳R0→0.12；罗马R0 0.45→0.35、宗教0.41、边境4（沿海匪患与西西里通道）；伊利里亚边境7、征额2.25、净收比0.30、本地官员0.45；加泰罗尼亚、埃布罗以北征额与净收为0（史实从未征兵，收入全部解入军库）；瓦莱R0 0.20、边境5；北意、南德并合时主权项0.25、外援0.30；那不勒斯外援0.50；西班牙其余外援0.60；瑞士R0 0.35、并合时主权0.30；华沙R0 0.25、并合时主权0.30；贝格在乙、丙层有"市场准入"开关（1811年4,000人请愿求并入）。

**史实校验（`hist`，1811—1812年驻军需求）**：荷兰1.37万、1.70万（锚点约1.5万）；汉萨0.61万—0.72万（警察即可处置）；伊利里亚2.2万—2.5万（峰值28,562人含对外防御）；罗马约0.7万（1810年约1万生力军）；瓦莱约900人（1810年12月约1,000人）。1813年外部机会出现时，荷兰升到3.9万、汉萨1.45万，重现"滞后爆发"。

### 敏感性（每轨道27组：驻军密度系数×调整速度×收编水平）
- 昙花一现（v3.1起1809年另设奥地利战争与瓦尔赫伦的外部机会事件，只影响1809年）：1815年余缺−10.5万至＋3.2万，已脱离0—2个；1830年所有组合都失去约3,830万人口（外圈、藩属与西班牙）。
- 最可能：所有组合稳定，1848年＋5.3万至＋6.1万。
- 强行成功：所有组合无叛离、无转向；1815年＋0.1万至＋4.0万，1848年＋3.6万至＋5.4万。（v2有3组在1830年前出现波旁西班牙改换保护人，v3没有。）

### v3与v2的主要差别
- 昙花一现最早的裂缝由1815年推迟到1816年饥荒之后的1817年；汉萨不再脱离；顶点应读作1814—1816年约4,940万（v2的README与第十二章草稿写"1813年约4,740万"，有误）。
- 强行成功轨道由"1812—1823年勉强打平"变为"1812年小缺、此后小有余"；去掉联邦化的慢性挤压由−6.8万减为−1.9万。
- 最可能与乙层主线的结论不变，数字小幅下调（驻军需求折减后，贝格、托斯卡纳等小单位的影响本来就小，下调主要来自征额与参数修订）。

### 已知局限
1. 没有内生化大国间战争：联军是否进攻法国本土、英国是否在荷兰登陆、普鲁士是否在俄国支持下起事，须由叙事推演补足；昙花一现轨道的模型终态（直辖约4,380万）因此高于叙事终局。
2. 抵抗指数、驻军密度函数、民族意识年增幅等为条件设定，只用D1、D2、Q1、Q2、P2卡与第十章所列锚点粗校。
3. 同盟层（C）沿用地区底值：波旁西班牙在乙、丙层的R在0.83—0.94之间，偏高；它只影响继承时"改换保护人"的判定，在乙、丙主线中未触发。
4. 内圈（旧法国以外的比利时、莱茵左岸、皮埃蒙特等）作为一个聚合单位，不计阶段；第十一章起草人建议拆为五区。
5. 干部供给没有设硬约束，只作指标；战时预算为条件设定。
