> 所有新写章节共用本文件，以保证国别、外交、行省化、上帝视角与年表各章前后一致。起草人如发现某项设定与证据冲突，在稿中写明理由，并在交稿时列入"对轨道设定的修改建议"，不得自行在不同章节采用不同版本。

## 〇、共同底座
- **外生事件在各轨道都照常发生**：1811—12年法国粮荒；1815年4月坦博拉火山喷发与1816—17年欧洲歉收；1817年霍乱在孟加拉出现，1829—32年经俄国传入欧洲；1845—47年马铃薯晚疫病；1846—47年欧洲经济危机。各国君主的自然寿命按史实处理（例如1825年亚历山大一世死、1835年弗朗茨一世死），但轨道分岔造成的宫廷变局另行推演。
- **拿破仑的身体**：按史实病程，1817—1820年间起病，死亡窗口设为1819—1825年，中心值1821年（外生设定，登记为"健康设定H"）；只有丙层可以把"健康到1836年"作为奇迹M1。
- **罗马王**（若出生）：史实1832年死于结核；各轨道默认照旧，丙层可作奇迹M5。

## 一、最可能轨道（甲层：拿破仑还是拿破仑，只在少数节点采纳当时的较好方案）

**分岔点**：1807年7月提尔西特以后（1803—1807年按史实）。依据：书稿原主线；附编的补算显示"从已经取得胜利的位置转向，需要改变的先前选择更少"。

| 年 | 设定 | 当时的依据 |
|---|---|---|
| 1807—08 | 不瓜分葡萄牙，不以借道为名大举入西班牙；对葡萄牙改为港口与商业施压 | 枫丹白露条约之外，拿破仑与西班牙宫廷往来中已有联姻与调停选项（费尔南多1807年10月11日请婚信） |
| 1808 | 西班牙宫廷危机以调停和联姻处理（费尔南多娶波拿巴家族女子），不在巴约讷废立 | 同上；1808年3月仍有人提出以联姻处理冲突 |
| 1808—10 | 封锁不再以并合海岸执行；许可证常态化；不并荷兰、汉萨、奥尔登堡。荷兰的残余并合风险约两到三成半（1810—1820），触发器是路易本人的去留、对英战事重开与1821年继承；**D-德1**：路易若让位，承认其幼子继位并设荷兰摄政会（第六章） | 路易国王与荷兰官员的反对；科隆商会、汉堡参议会的陈情；拿破仑本人说荷兰行政"比法国更省钱"（研究卡NL第387行）；1810年7月路易的让位安排 |
| 1809 | 奥地利是否开战为分岔：主线不开战，开战可能约两成到三成半（第五章"复战三条件"规则；埃尔福特第10条封死第三项条件）；若开战，法国速胜、和约有限 | 卡尔大公的军事评估；1808年施塔迪翁主战派与梅特涅的判断以西班牙牵制为前提（Sherwig p.207转Kraehe） |
| 1808.4—1809 | 撤回1808年4月2日对马尔凯的并合，不并罗马，教廷以战时关闭港口换保留世俗领地（**D伊3**，第七章）；托斯卡纳保留埃特鲁里亚王国（不瓜分葡萄牙，王室无从补偿；模型v3.1） | 1808年4月11日教廷照会 |
| 1810 | 仍与哈布斯堡联姻（俄婚受阻），1811年皇子出生。没有1809年战败，奥方动机改为"楔入法俄同盟"（中；第五章）；登记"婚事不成→皇子链条中断"为备选 | 史实；埃尔福特第10条使俄国成为奥地利的敌人 |
| 1810—11 | 按拿破仑1810年2月反稿签署不援助复国的公约，同时给出三项事实：但泽驻军定下最低额、法军不入华沙公国、公国兵额以财力为限；容忍俄国1810年关税与中立船；奥尔登堡不并（甲层没有奥尔登堡事件）。1811年起按1808年巴黎公约随偿款撤出奥得河要塞，偿款过半即交还格洛高 | 旺达尔卷二L2132—2136：亚历山大认为没有"永不复国"一条的公约"毫无意义"，所以软公约必须配事实（第四章）；涅谢尔罗迭1811年10月备忘录第2、4项；拿破仑1811年4月10日提出的"同时裁军" |
| 1812 | 不入侵俄国 | 科兰古、康巴塞雷斯、达律等人的反对意见 |
| 1811—14 | 争取英法海上停战（工作窗口），全面和约次之 | 1812年巴萨诺—卡斯尔雷往来；西班牙王朝问题已不存在 |
| 1812 | 不占瑞属波美拉尼亚（**D-德4**） | 许可证常态化后走私通道不再是开战理由 |
| 1815—30 | 有限霸权：直辖约3,840万人（托斯卡纳保留埃特鲁里亚王国）；意大利王国、那不勒斯、威斯特法利亚、华沙、荷兰为藩属；南德、萨克森、瑞士、丹麦、埃特鲁里亚为同盟 | 书稿原主线；模型v3.1：兵力余量1815年约6.6万、1830年约6.8万、1848年约5.7万 |
| 1818 | 普鲁士4.2万人限军（1808年巴黎公约，十年）期满：续限或改对等裁军（**D-德6**），以新的辅助条约与军用道路协议换有限扩军；2月卡尔·约翰继位：以默许继位换瑞典承认丹挪现状、放弃挪威主张（**D-德5**） | 1808年分立条款第2条；奥布家族公约先例（第五、六章） |
| 1828 | 1803年瑞士军事协约（25年）期满，续约等于一次对法关系公投 | 第六章 |
| 1821（窗口） | 皇帝死亡，幼主摄政（1813年摄政法），财政—继承交涉带来有限宪制 | 1813年摄政法、1815年《附加法》构件 |
| 1848 | 有限立宪的法国核心；多中心的欧洲秩序 | — |

## 二、昙花一现轨道（"用拿破仑的办法强推行省化"，只去掉1812年的灾难）

**性质**：这不是作者推荐的路线，而是检验"按史实的扩张逻辑一直推下去会怎样"。1803—1811年按史实；1812年用一个当时说得通的决定避开俄国灾难；此后并合照当时已有的动议继续推进，统治方法照旧（重征兵、封锁、与教皇冲突、偏袒法国工商）。

| 年 | 设定 | 依据或登记 |
|---|---|---|
| 1812 | 与俄国在4月最后通牒基础上达成妥协：许可证贸易、俄国维持对英直接贸易禁令、奥尔登堡以同等领土补偿；分歧点（中立船、先撤普鲁士驻军）以分阶段方式解决。不入侵俄国 | 1812年2月25日拿破仑三条件与俄方4月条件在三点上重合（A2核查）；科兰古、达律的反对意见。登记为决定D-F1（可信度中低：史实上拿破仑当时已决心开战） |
| 1812—14 | 大军转向西班牙，1813年拿破仑亲征；威灵顿退守里斯本—托雷斯韦德拉斯，英军靠海上补给坚守；游击战持续 | 1810—11年马塞纳受阻于托雷斯韦德拉斯的史实；奥曼、埃斯代尔关于游击战的材料 |
| 1813 | 并合埃布罗河以北（阿拉贡、纳瓦拉、比斯开）为法国省 | 1810年2月8日军政府敕令（Woolf p.52）；1808年2月24日法国照会已要求以埃布罗以北换整个葡萄牙（第十二章注〔行32〕） |
| 1813—14 | 贝格、威斯特法利亚逐步并入法国（关税与征兵执行理由）。并合队列到此为止：按研究卡F2的静态余量，高压区每千人15—25人时只能再容纳约590万—980万人，"贝格＋威斯特法利亚＋埃布罗以北"约430万人已是上限；意大利王国并入只放在丙层（第十章） | 1810年已把威斯特法利亚北部与汉诺威北部划入法国的先例；贝格请愿：施密特1905年书印页383—385、397—399（1810年11月14日埃尔伯费尔德陈情，巴门与雷姆沙伊德请愿，1811年5月3日请愿，1811年8月罗德雷两份敕令草案，9月9日贡比涅商务会议）。请愿要的是市场准入，以"关税与征兵执行"为理由的并合满足的是巴黎的需要 |
| 1810—20 | 教皇继续被拘；拒誓与教区空缺延续；封锁与"法国优先"继续 | 史实1809—14年的延续 |
| 1812—20 | 英法战争延续（利物浦内阁；英美战争1814年底结束后英国更集中于欧洲） | 英国政治的史实延续性 |
| 1812—15 | 北欧线照史实：1812年1月占领瑞属波美拉尼亚与4月圣彼得堡秘约照旧；法俄妥协后俄国不再为瑞典出兵，瑞典依靠英国；1813—1815年瑞典在英国海军支持下攻挪威（中低），丹麦或以宪法换挪威人服从，或失挪威 | 第六章 |
| 1818—20 | 法国财政吃紧，延长普鲁士限军与要塞占领——这是1821—22年普鲁士转向的触发条件之一 | 第五章 |
| 1816—17 | 坦博拉饥荒遇上封锁与征发：荷兰、汉萨、莱茵、意大利出现粮食骚乱与逃役潮 | 1816—17年各地饥荒史实；1811—12年粮荒时的法国应对 |
| 1817—20 | 财政：非常领域收入枯竭，出售公社财产（1813年3月20日法）之类的办法再用；增税与强制借款 | 1813年史实做法 |
| 1820 | 南欧革命浪潮以另一种形式出现：西班牙自由派与游击武装、那不勒斯烧炭党、意大利军官 | 史实1820年浪潮的社会基础仍在 |
| 1821（健康设定H） | 拿破仑死；罗马王10岁；玛丽·路易丝摄政，摄政会按1813年法组成；梅特涅影响摄政；约瑟夫、热罗姆、欧仁、缪拉、各元帅各有打算 | 1813年摄政法；玛丽·路易丝与梅特涅的史实关系 |
| 1821—25 | 崩解：西班牙失守→德意志起事（普鲁士在俄国支持下重演1813年动员，国民军按人口约3%摊派；英国可能像皮特1805年方案那样支持普鲁士在西面充当屏障；萨克森再次投向奥地利）→荷兰起义与英国登陆→意大利诸王各自求存（缪拉式倒戈）→奥地利以调停者身份索回伊利里亚与北意；华沙公国转投俄国，得到俄皇兼王的王国（亚历山大1811年报价的兑现），引出1822—1825年萨克森—波兰问题重演 | 1813—14年各地转向的史实机制（里德条约式的保证人转换）；第四、五章 |
| 1825—30 | 法国本土保住比利时与莱茵左岸与否，取决于摄政能否守住核心；波拿巴王朝在缩小的法国存续或被取代，两种都要推演 | — |

**要回答的问题**：顶点在哪一年、有多大；最先断的是哪一环（兵、钱、教会、市场、继承、外敌）；谁先倒戈；崩解是否会把早期并合内圈一起带走。

**模型v3的答案**：顶点1814—1816年直辖约4,940万；1812年加泰罗尼亚失控，1816年饥荒缺兵约20.5万，1817年荷兰、罗马、伊利里亚、埃布罗以北失控（汉萨留在"顺从的假象"里）；1821年意大利王国、南德、那不勒斯、瑞士、华沙改换保护人；1822年放弃西班牙。变体：1814年就放弃西班牙，继承时没有藩属与同盟转向。

## 三、强行成功轨道（乙层＋丙层）

### 乙层主线：每个节点"听取当时最好的那条建议"，加上少量登记的运气

**分岔点**：1803年起逐节点改变，但保留赢得1805—1807年战争的路径（选择标准：让法国的优势活过皇帝本人；附编补算显示从胜利位置转向成功机会较大）。

| 年 | 设定 | 当时的提出者或运气登记 |
|---|---|---|
| 1803 | 英法战争照旧重开；1803年起停止向圣多明各追加远征，事实停火通商；1814年和约后以条约正式承认海地（第十四章） | 1803年远征军已溃，法国当时已放弃路易斯安那计划；"1803年即承认海地独立"找不到当时法国政府内的主张者，已删 |
| 1804 | 不越境抓捕、不处决昂吉安公爵 | 康巴塞雷斯的反对意见 |
| 1805 | 奥地利参战，乌尔姆、奥斯特里茨按史实 | 史实 |
| 1805.10 | **运气L1**：联合舰队留在加的斯，没有特拉法加 | 9月14日出航令明确要求出航，留港只能是偶然：罗西利10月12日才到马德里、驿路瘫痪；10月7日曾因东风过强取消起锚；10月8日军事会议上格拉维纳与西班牙军官主张锚泊待攻（E包项1）。可能性**中低**。舰队留港后仍被长期封锁，其存续取决于法西同盟不破裂——史实1808年6月14日罗西利的5艘舰在加的斯投降 |
| 1805.12 | 普雷斯堡：领土条款基本按史实（威尼斯归意大利、蒂罗尔归巴伐利亚），但赔款较轻，附商约，定期兑现第5条分冠承诺；可向奥地利提出同盟，但奥方会婉拒（1806年奥地利对拿破仑的同盟提议一律"客气回避"，Butterfield pp.110—113），乙层的实际收获是商约与较轻赔款。塔列朗方案中的东方补偿不采用（同一块多瑙河土地不能同时许给奥地利和俄国） | 塔列朗1805年10月17日斯特拉斯堡报告与附约草案、12月5日再陈（Dard pp.128—138） |
| 1805.12—1806.2 | 申布伦、巴黎两约：普鲁士以托管人身份占领汉诺威，待全面和约处分；不迫其吞并，不迫其对英封港（第八章，中低） | 普王对申布伦条约的附条件批准——要汉诺威、不要同英国开战（第八章注交109）；英国红线：皮特1805年"比利时可以，汉诺威绝不"、格伦维尔1806年10月要求"立即无条件归还"（Sherwig pp.167—168、177—178）；拿破仑自己的"以占领地抵押全面和平"原则。原写"豪格维茨最初的方案"无本地出处，已删 |
| 1806 | 对福克斯的谈判：先让出西西里（英方的必要条件）；汉诺威归还英王，普鲁士另获补偿（补偿池几乎每一块都有否决者，是最薄的一环）；把俄国纳入（乌布里尔条约条款更优）；不对塞利姆作"保证土耳其拥有两公国与塞尔维亚"的点名保证（1806年12月1日信的写法与埃尔福特冲突；依据塞巴斯蒂亚尼1806年5月训令"把奥斯曼整体从俄国手里争回、法国在巴尔干不要新领土"） | 塔列朗的"实际占有，随后按等价交换调整"基础（雅茅斯1806年12月30日下院证词）；福克斯1806年6月26日训令；尚帕尼的交换清单。L2的偶然变量另加"伦敦随布宜诺斯艾利斯消息提价"（格伦维尔9月22日、29日信）。**运气L2**：和约须在福克斯去世（9月13日）前签字且亚历山大批准（可能性中低） |
