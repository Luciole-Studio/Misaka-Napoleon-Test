

### 5.4 1806｜早窗谈判：汉诺威归还英国，北德交普鲁士

| 项 | 内容 |
|---|---|
| **决策** | （a）以"实际占有＋等价交换"为基础与Talents政府成交：**汉诺威归还乔治三世**、西西里留波旁、马耳他归英、殖民地按实际占有调整、附商业条款；（b）莱茵邦联成立但**只做仲裁＋配额＋陪臣保障的窄版制度化**，不建统一邦联宪法；（c）对普鲁士不玩汉诺威两面交易，改以北德商业-宪制角色补偿 |
| **英国** | 【锚】B1（1806-12-30 HC cc248/250 Yarmouth）：Talleyrand口头以**实际占有＋等价交换**为基础；政府承认无法方正式文书。→ 【推】把口头基础写成文书并附汉诺威归还，是本窗口成交与否的分水岭（中置信） |
| **普鲁士** | 【锚】PR：1806年开战的直接引信是汉诺威双重交易＋南德法军存在。移除引信→普鲁士留在武装中立，1806年无耶拿 |
| **南德** | 【锚】G1四条件：担保独占（所得取自哈布斯堡与教会）＋血税上限＋主权底线（1808巴伐利亚宪法的首要动机正是抢先阻止邦联统一宪法）＋经济通道。窄版制度化恰好同时满足四条 |
| **G2北德** | 顺从带；无法军在场需求即无治安账 |
| **结算** | 人力540k；财政+52m；海军升至110m | 
| **奇迹** | 0（M-B1"英国签约"为0.40–0.60的中等概率反应，不计奇迹） |
| **与史实分叉** | 史实1806-10耶拿，1806-11柏林敕令 |
| **F1计价** | C3节点（对英写定且不加价）是本路径**唯一一个非工具性色彩较重**的节点，先验0.15–0.25；本卡的工具性重写方案：把和约包装为"以汉诺威赎回法国在北德的自由手＋以商业条款换取财政收入"，可把先验提到0.30–0.45 |

### 5.5 1807｜对俄给关税容忍，不造波兰王国

| 项 | 内容 |
|---|---|
| **决策** | （a）大陆体系改为**保护性财政关税**（§3.4）；（b）对俄签商业-政治条约：承认俄国关税自主与中立航运，法国换取俄国不加入反法联盟、不为英国提供大陆锚；（c）**不创设华沙公国**，波兰复国作为对俄威慑期票留在抽屉里；（d）普鲁士维持残普现状 |
| **俄国** | 【锚】R1 L209/L214：关税容忍是唯一六列同击的让步；L288："它买到的是'不战'，不是'亲法'"。【锚】R1 L26/X2：若许可证/关税经济可持续，冷和平半衰期由4年上调至**8–12年**。→ 最可能反应：**非交战状态**（0.35–0.50，中置信） |
| **波兰** | 【锚】PL：复国波兰与俄国盟友在1807互斥；公国是"忠诚度最高、榨取率也最高"的资产但财政基座自第一天起不能闭合。→ 不建公国＝放弃35–55k常备兵，但也放弃了俄国的不可保险安全困境 |
| **北欧** | 【锚】SC：无严格封锁即无1807哥本哈根事件的法方动因，丹麦不被推入破产，瑞典不必被逼成敌人 |
| **美国** | 【锚】US：不扣美国船＝支付了价格；中立运输与白银管道保留；P(英美战争)由S3的0.55–0.75回落到S2的0.30–0.45 |
| **结算** | 关税净由−133.5至−53m（严格版）改善为**+36至+76m**；海军升至120m |
| **奇迹** | 0（M-B2俄国十年不战＝0.35–0.50） |
| **F1计价** | C4节点：工具性（换东境安全＋财政），先验0.35–0.55 |

### 5.6 1808｜B4b：不废西王

| 项 | 内容 |
|---|---|
| **决策** | 西班牙内部危机（El Escorial→Aranjuez）照常发生，法国**以调停人而非接管者入场**：承认费尔南多七世、把1808-01-10的书面"Consiento de buen grado"去条件化（SP1 L14：史实中每一次"同意"都附带使其当下不可执行的条件且价码逐月抬高）、维持同盟与补贴安排 |
| **西班牙国家** | 【锚】SP1 L12：B4b是唯一不引爆机器自毁装置的接管协议；L67：同盟态＝25,000远征军＋港口＋船厂＋对葡通道 |
| **西班牙社会** | 【锚】SP2 L11：起义开关三条件（斩首王朝／首都屠杀／旧当局瘫痪）一个都不满足；1796–1808十二年同盟零反法起义；1823年5.6万法军以保王旗号入境几乎无民众抵抗。→ **接受（中高）；风险在宫廷不在街头** |
| **葡萄牙** | 【锚】PT：1803–06付费中立（月100万里弗×16个月实测）可延续，不必执行枫丹白露 |
| **墨西哥/南美** | 【锚】MX：S-A档（波旁续任亲法＋英西默契）年实得130–400万pesos；【锚】SA："法国唯一美洲路径是通过马德里而非大西洋" |
| **印度洋** | 【锚】IN2：无西班牙起义→1808-05/06的56舰19,600兵方案不再被欧洲优先事项挤掉（该卡自判B4为"本单位最大单点改判杆"） |
| **结算** | 人力节省29–36万（SP1 L67）；财政+43m；海军130m |
| **奇迹** | 0 |
| **F1计价** | C5节点：工具性（王朝收益＋25,000军＋白银管道），先验0.35–0.55 |

### 5.8 1810｜不并荷兰汉萨，改分层准入；奥地利联姻

| 项 | 内容 |
|---|---|
| **决策** | （a）荷兰维持藩属王国（路易的抗拒源于封锁执法，在保护性关税下消失）；（b）汉萨、贝格、北海岸不并入，改用**法国优先分层准入**（X2形态A：1830视点0.50–0.60）；（c）与奥地利联姻 |
| **荷兰** | 【锚】NL：兼并模式的全部毒性来自撷取方式——tiercé把78m年金削到26m，"恰烧毁兼并所欲攫取的最大资产"；西荷兰须常驻15,000法军至1813。→ 不并＝省下15,000驻军＋保住阿姆斯特丹资本市场 |
| **汉萨/北德** | 【锚】G2：海岸带并入财政自败（汉堡1813罚金48M fr≈汉萨年预期税1.3倍）；【锚】X2：贝格1811四千人签名请求并入被法国保护主义拒绝——**分层准入正是对该请求的正向回答** |
| **X1金融** | 【锚】X1：每并入一个金融中心即摧毁其资本存量与自己在那里的收款能力；不并＝阿姆斯特丹、汉堡、法兰克福继续可用 |
| **结算** | 人力540k；财政+23m（海军已升至150m）；**外圈治安账6–10万从未发生** |
| **奇迹** | 0 |
| **F1计价** | C7节点：非工具性色彩重（放弃直接支配），先验0.15–0.25；工具性重写方案＝把分层准入包装为"法国工业的欧洲特惠区＋可核算的关税收入"，可提至0.30–0.45 |
