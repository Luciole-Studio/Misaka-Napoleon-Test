# C12　俄国问题：避免1812不等于锁定俄国

## 结论

【裁量｜中等置信】最有文献基础的替代，不是“仅取消进军莫斯科”，而是在1811年尚有谈判余地时，以商业通融、前沿兵力限制、普鲁士安全和奥尔登堡补偿换取法俄武装共存。它需要拿破仑接受俄国并非普通藩属，以及大陆封锁不能无限压倒俄国自主利益。**这可保存法国大陆优势，却不是把整个欧洲、尤其俄国，纳入法国排他控制的办法。**[D3–D5]

【裁量｜高置信】目前证据没有证明“亚历山大在任何让步下都必战”；但俄方的和平方案明确以恢复俄奥力量、重建均势为长远目的。因此，“1812可以避免”不能延伸为“战争永远不会再来”。[D1、D3、R1]

【裁量｜中等置信】停驻维捷布斯克／斯摩棱斯克有回溯性亲历证词，不能说纯属后人发明；然而它仍有驻军供养、冬季战线、俄军扩充、波兰征募与粮运竞争等问题。保存军队、减少远征损失、获得政治和平是三个不同目标，没有证据允许以第一个替代后两个。[M1–M3]

【裁量｜高置信】“波兰复国＋立陶宛全民动员＋俄国农奴解放”不是本轮材料已证明存在的一套成熟共同方案。复国宣言、法国附条件支持、地方正规军组织、社会革命必须分开评估。[P1–P4]

**交付边界：**这是有保留的研究结论，而非全部原件验收通过。Lieven专著、Caulaincourt法文卷I、Riehn正文、关税敕令全文和同期停驻命令尚缺；见第八节。随附三份证据札记保留较长引文与检索限度，本报告不把代理札记本身当作历史原始来源。

## 一、检验方法与证伪结果

【方法】先分别检验：①当时是否出现选项；②是否获授权；③资源能否支撑；④俄国是否可能接受；⑤达成后如何维持。文献能直接证明①，不因此自动证明②–⑤。概率带是有条件的比较裁量，不是频率估计；“置信度”则指判断的证据强弱。

【方法】特别防止把战争准备、预期战争、拒绝屈服、主动开战与决意推翻拿破仑混为一谈。1811年初、1811年秋、1812年春、入侵后及莫斯科占领后分期处理。

| 原证伪条件 | 本轮检验结果 |
|---|---|
| 亚历山大面对任何让步均已决意进攻 | 【裁量】未成立。条件性波兰方案、十月谈判备忘录、Esdaile对Lieven的概括均构成反证；不能反向证明俄方永不进攻。 |
| 在斯摩棱斯克停驻也必然无法维持 | 【裁量】不能作绝对判决；Clausewitz提出强反论，Caulaincourt记录觅草困难，现无完整冬营资源账。该分支从“胜利秘诀”降为高约束试验。 |
| 全面复国必然同时引发奥普俄三线 | 【裁量】材料证明对奥承诺与全面复国有冲突，尚不证明三国同时参战为必然。不能把未批准的领土交换或推测反应当事实。 |

## 二、裂解编年与因果权重

下表的【事实】包括文书存在、文书写了什么，不代表认同其自我辩护。

| 时点 | 可核事件／文书及出处 | 对解释的意义 |
|---|---|---|
| 1808–1809 | 【事实】Kurakin就俄国—汉萨贸易困难提出改善交往的建议；Makarov据外交文书讨论俄方未采纳，俄国不愿因松绑危及同盟是作者的解释。[E2，印刷pp.17–22] | 【文献推断｜Makarov】经济困难可以与暂时维持联盟并存；它不是自动破盟开关。 |
| 1809末–1810初 | 【事实】俄婚试探与波兰保证交涉并行；法方说明“Ce n’est pas une demande formelle que je fais”。[D2，卷II婚姻谈判段] | 【裁量】婚姻挫折不是单独充分原因，需放回波兰和同盟谈判。 |
| 1810年1月 | 【事实】考兰古签署的公约含“Le royaume de Pologne ne sera jamais rétabli”；拿破仑未批准。Vandal记1月4日，Bogdanovich加工本记旧历12月24日／新历1月5日，日期存在一天差异，暂不强行抹平。[D2；R3] | 【文献推断｜Vandal】保证结果永不发生，比法国保证不援助复国更强。不能写成生效条约被法国随后违反。 |
| 1810年2月 | 【事实】拿破仑提出替代公约，反对承诺无法控制的未来，改为不向恢复波兰的力量提供帮助。[D2，卷II拒绝公约段、注386附近] | 【裁量】是义务范围与可信度之争，不是“完全不愿作任何保证”。 |
| 1810末–1811初 | 【事实】奥尔登堡吞并与俄方19／31日十二月关税敕令成为公开争端；俄方援引提尔西特第12条及王朝权利，法国提出Erfurt等补偿。[D4；R3] | 【裁量】王朝、条约和安全权利并存；不能只写皇室私怨。敕令全文未核，不宣称已校清每种商品税率。 |
| 1811年初 | 【事实】Vandal所引Alexander—Czartoryski通信将进攻机会系于华沙倒戈：“Mais tout change de face si les Polonais veulent se joindre à moi”。[D1] | 【裁量】证明有条件进攻筹划，不证明无条件必战；通信中的兵额是方案估计，非实到军数。 |
| 1811年2–3月 | 【事实】法国愿让俄方秘密不执行焚毁法国商品，并讨论等值换出俄货的贸易条约；同时把俄英媾和视为战争红线。[D4] | 【裁量】在某些贸易手段上存在弹性，但对英战略与俄自主权的冲突更难化解。 |
| 1811年10月 | 【事实】Nesselrode按沙皇命令整理此前谈话，提出五议题和奥地利担保；主张不因空泛波兰保证而减让更重要事项。[D3] | 【裁量】最完整避战锚点，但不是已经批准、交付法国的正式条约方案。 |
| 1812年4月8日文书 | 【事实】Vandal转引俄方要求先撤出普鲁士、瑞典波美拉尼亚、缩减但泽驻军等，再讨论贸易、对英措施和奥尔登堡补偿；中立贸易不作英国贸易附属而排除。[D5] | 【文献推断｜Vandal】他判为不对称、近于最后通牒；“俄方故意提出绝不可能接受条件”是作者动机判断，不能作为无争议事实。 |
| 1812年5–8月 | 【事实】布加勒斯特和平5月16／28日签署；俄瑞Åbo补充协定8月18／30日签署。[R4–R5] | 【裁量】两翼外交改善俄国处境；八月安排不能倒算为六月既有援兵。 |
| 1812年夏–冬 | 【事实】波兰宣告复国、立陶宛正规部队组织、附条件法国支持及远征展开；拿破仑年底公开表示拒绝解放俄国农奴。[P1–P4] | 【裁量】这些政策各有时滞、对象和社会条件，不能拼成一项无成本动员按钮。 |

【综合推断】裂解更适合解释为三层相互强化：经济分配与贸易自主争端；波兰—普鲁士前沿安全困境；双方承诺可信度不足。婚姻、奥尔登堡和荣誉语言放大危机，但不单独解释战争。证据不能识别各原因的独立百分比权重。[D1–D5、E2、R1–R3]

## 三、经济证据：严重冲击不等于“经济崩溃必战”

【文献推断｜Troshin 2015】作者以1807＝1估计贸易条件（出口价格指数／进口价格指数），正文给出1808年0.43、1809年0.69、1810年0.74、1811年大致不变。1808年是严重冲击，其后有所恢复；0.74并非恢复到基准。[E1，p.856]
