# How to Use Text & Data from the DFIH Project

Every information visible without login on the website can be used freely
with the proper
[citation](https://dfih.fr/cite)

An authenticated interface is being developed, that will allow you to
extract data series in tabular file format (csv) and access an
experimental index generation tool.

In order to create your account, please provide us with some information
about you and your project.
