

【推·中】即使前两项都中，第三项（英国在1–3个月内签有限和约）也只有0.25–0.45，且**其成立条件是法国主动放弃最大索取**——B1a L9明确"保留王朝、议会、公债和主体舰队"不是已核的法方保证书。也就是说：**入侵成功之后，法国仍然要走路径B的谈判条款，才能把军事胜利转成政治结果。**入侵没有省掉任何一项政治让步，只是在前面加了两个硬奇迹。

【推·中高】第四项（M-A4）是本路径的结构性自伤：把25万主力放到海峡对岸，正是奥俄组织第三次同盟的最强诱因。史实中同盟恰在1805年法军仍在布洛涅时成型——这不是运气不好，是**可预测的反应函数输出**。

**裁定**：路径A在严判据下2件奇迹、宽判据下3件，联合概率0.0004–0.0068。**不能作主线**；但它不是"不可能"，而是"用两个不可购买的外生事件换一个本来可以用条约买到的结果"。

## §5 路径B｜S2′ 最优构造线（1803–1815）：本卡的主线

设计原则（每一条都可回溯到某张卡的反应函数）：
1. **不追求任何单项最大化**（T3）；2. **凡让步必包装为工具性收益**（F1 L143）；3. **凡可用条约买到的，不用战争买**；4. **凡不能自持的省，不并**（D2）；5. **凡削弱盟友财政的执法，不做**（SC/X2）；6. **把皇帝的单边冲动导向非红线方向**（F1 L251）。

### 5.1 1803｜不为马耳他重开战

| 项 | 内容 |
|---|---|
| **决策** | 接受第三方（俄国）调停马耳他争端：英军延期驻留换岛屿中立化与十年期限；同时停止把埃及侦察（1803-01-30 Moniteur塞巴斯蒂亚尼报告"六千法军足以再征埃及"）作为公开施压工具 |
| **英国** | 【锚】B1b L43：Addington"亚眠＋1803接受调停"——**可由在位政府交易，不需要政权革命**。→ 最可能反应：接受调停、战争推迟；对法警戒不解除 |
| **俄国** | 【锚】R1：亚历山大的自我定位是欧洲仲裁者；调停角色是零成本满足。→ 反应：接受调停人身份，法俄关系起点优于史实 |
| **奥/普** | 无触发即不动（A：1805同盟需要意大利加冕＋吞并热那亚这类具体挑衅） |
| **结算** | 人力540k（TIGHT）；财政+72m；海军90m；X1承包商体系不被拉到极限 |
| **奇迹** | 0 |
| **与史实分叉** | 史实1803年5月英国宣战〔通说日期1803-05-18，本卡未从原件核〕，随后十一年无和平 |
| **F1计价** | C1节点：工具性（保财政与海军重建期、把战争责任留给对方），先验0.45–0.60 |

### 5.2 1804｜称帝，同时把"领土交易清单"写定

| 项 | 内容 |
|---|---|
| **决策** | （a）称帝；（b）以书面清单对英列明法国愿意固定的边界与愿意交换的对象，并承诺**不再加价**；（c）昂吉安案以司法程序而非处决结案 |
| **英国** | 【锚】B1b L9："法国如果把领土交易写定、不反复加价，可将和平提前到这一窗口"。→ Pitt 1804回任后仍将组织联盟，但**补贴外交的说服力取决于法国是否继续扩张**；1804年不成交，但谈判通道保留 |
| **俄国** | 【锚】R1：昂吉安处决是1804年彼得堡断交的直接引信。→ 司法处置版下，断交推迟或不发生 |
| **结算** | 财政+72m；海军90m | 
| **奇迹** | 0 |
| **F1计价** | 昂吉安节点可包装为"不给欧洲王室把新王朝定义为弑君者的口实"（王朝收益）→ 工具性，先验0.30–0.50 |

### 5.3 1805｜意大利王冠取，热那亚不并；给奥地利出海口

| 项 | 内容 |
|---|---|
| **决策** | 取意大利王冠但**严格执行1805年法令第3条的分冠条款**（IT1：1805 art.3自动分冠是后来把王冠交给罗马王的制度通道）；**不吞并利古里亚**；对奥地利给出三样：剩余疆域与王朝安全、亚得里亚商业海口（的里雅斯特-菲乌梅）、明确边界 |
| **奥地利** | 【锚】A卡主线：给王朝安全＋商业海口＋明确边界＋在法国秩序内阻挡俄国与过强普鲁士的作用→"跨一次继承的不平等合作伙伴"。【机】1805年第三次同盟的近因是意大利加冕＋吞并热那亚；移除后者即移除同盟的正当化事由。→ 最可能反应：**不加入同盟**（中置信；A卡S5-A路） |
| **俄国** | 无奥地利则无大陆战场；R1的"C层"关系尚未启动，但也无战争 |
| **英国** | 继续封锁与补贴外交，但**无大陆伙伴**（B1b：无盟友并不立即等于接受法国条件，但把其选项压回蓝水） |
| **结算** | 人力540k；财政+62m；**无奥斯特利茨，也无特拉法加**——因为没有渡海计划就没有维尔纳夫的舰队集中令（F3：海军资源不被单次决战消耗） |
| **奇迹** | 0（本年所需的只是奥地利不动，A卡判其为条件反应而非低概率事件） |
| **代价** | 法国放弃了一次"证明霸权"的会战胜利。F1计价：C2节点，工具性（拆同盟＝包围收益），先验0.45–0.65 |

### 5.4 1806｜早窗谈判：汉诺威归还英国，北德交普鲁士

| 项 | 内容 |
|---|---|
| **决策** | （a）以"实际占有＋等价交换"为基础与Talents政府成交：**汉诺威归还乔治三世**、西西里留波旁、马耳他归英、殖民地按实际占有调整、附商业条款；（b）莱茵邦联成立但**只做仲裁＋配额＋陪臣保障的窄版制度化**，不建统一邦联宪法；（c）对普鲁士不玩汉诺威两面交易，改以北德商业-宪制角色补偿 |
| **英国** | 【锚】B1（1806-12-30 HC cc248/250 Yarmouth）：Talleyrand口头以**实际占有＋等价交换**为基础；政府承认无法方正式文书。→ 【推】把口头基础写成文书并附汉诺威归还，是本窗口成交与否的分水岭（中置信） |
| **普鲁士** | 【锚】PR：1806年开战的直接引信是汉诺威双重交易＋南德法军存在。移除引信→普鲁士留在武装中立，1806年无耶拿 |
| **南德** | 【锚】G1四条件：担保独占（所得取自哈布斯堡与教会）＋血税上限＋主权底线（1808巴伐利亚宪法的首要动机正是抢先阻止邦联统一宪法）＋经济通道。窄版制度化恰好同时满足四条 |
| **G2北德** | 顺从带；无法军在场需求即无治安账 |
| **结算** | 人力540k；财政+52m；海军升至110m | 
| **奇迹** | 0（M-B1"英国签约"为0.40–0.60的中等概率反应，不计奇迹） |
| **与史实分叉** | 史实1806-10耶拿，1806-11柏林敕令 |
| **F1计价** | C3节点（对英写定且不加价）是本路径**唯一一个非工具性色彩较重**的节点，先验0.15–0.25；本卡的工具性重写方案：把和约包装为"以汉诺威赎回法国在北德的自由手＋以商业条款换取财政收入"，可把先验提到0.30–0.45 |
