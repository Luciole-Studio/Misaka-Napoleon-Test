## §23 对应的声明（应登记而未能登记者）

### 声明1｜重写 §22 的 P₁ 定义（claim_type: inference）
IT2 t_8f2668 提供 1799 帕特诺珀共和国例：P₁ 无（法国的无根客户共和国）＋P₂ 有（Ruffo 的 Sanfede 以波旁名义、俄土舰队接应）→ **五个月全损**。但帕特诺珀共和国本身**是**本土政权（那不勒斯雅各宾派），却落在 P₁ 无的一行。故 P₁ 的正确判据不是"是否本土"，而是：
> **客户政权是否拥有独立的社会基盘与自己的财政-军事能力。**
缪拉王国有（国家机器、军队、废封建后的土地受益阶层）；帕特诺珀无（基盘窄局于城市知识层）。
另：矩阵左上格现有实测——1806–15 那不勒斯全王国（P₁ 波拿巴系藩属 vs P₂ 巴勒莫波旁，有正统索赔＋英国刀剑＋masse 网络）→ 实测即本卡预测的"长期争夺"。本卡右侧格现有**跨战区两个独立实例**（1799 帕特诺珀与 1808 圣多明各）。

### 声明2｜B 层的否定理由升级为"被 C 层支配"（claim_type: inference）
法国在海地扶立的任何客户政权都会是**帕特诺珀型（无根）而非缪拉型（生根）**：缪拉靠**废封建＋卖教产**买到一个土地受益阶层；而海地的土地已由 1805 宪法总则第 12 条全部收归国有、再由佩蒂翁分给军官士兵，**教产亦无可卖**（1805 宪法帝 50–52 条：不设国教、国家不供养任何教士）。
→ 法国能给客户政权的东西，海地现政权已经拥有；法国额外能给的只有承认与市场准入——**而这正是 C 层无需扶立政权即可给的**。
→ **B 层在结构上被 C 层支配（dominated）**：凡 B 能实现的目标 C 都能以更低代价实现，而 B 额外承担"扭转一个无根政权的存活"这项成本 C 不承担。**概率带 0.12–0.30 不改，但理由从"可信度低"升级为"被支配"——后者是更强的否定。**
实证支持（本卡自有材料）：1814 马卢埃方案给克里斯托夫的是**托尔蒂岛**、给佩蒂翁一派的是"例外承认与白人平等的公民权"——**两项都低于它们已经拥有的**。

### 声明3｜海外客户政权继承宗主国的存活概率（claim_type: inference）
IT2 给出左上格的出口规则：那不勒斯的长期争夺**以 P₁ 的欧洲级担保人崩溃为解**（1814–15 帝国塌→Tolentino→五周→移交时"惊人平静"，内保卫队 2–3 万维序、前政权雇员全留任；Blanch／De Nicola 经 Davis pp.272–274）。
→ 推论：任何 B 层或带藩属的 D 层方案，其 1848 年存续概率上界是 **F5 给出的波拿巴王朝存续至 1848 的 40–55%**（无条件加权），而非当地治理绩效。
→ **但海地的出口与那不勒斯相反**：1815 年那不勒斯的官僚机器被回归的波旁整体接收（故"平静"）；海地**没有一个能接收法式客户政权的外部索赔者**。宗主国一旦崩溃，法式客户政权不是"换旗留任"而是**被海地国家吸收——即全损且无残值**。这使 B 层的期望回报进一步低于其名义概率。

### 声明4｜D 层改用期限表述而非概率微调（claim_type: inference）
IT2 纠正：那不勒斯的 23–35% 只是**镇压峰值份额**，军事总负担 **65–80%**；靠**削债 33%＋变卖 1,300 所修院**的一次性缓冲续命，**1812 年缓冲耗尽**（"已无领地可卖"）。故正确表述是"藩属模式把不可持续推迟约十年，并由当地债权人与教会埋单"。
**本卡用自有材料验证了同一期限，而且是对 D′ 的**：西班牙 1809-07 重新接管圣多明各东部，该行政被同时代称为 **"España Boba"**，并于 **1821 年短命独立、1822 年被海地并吞——存续十二年**。
→ **D′（归还西班牙主权、只取条约性土地与商业准入）把财政负担转给了一个已被实测不能承担它的伙伴。** 除非法国补贴（而补贴即向 D 收敛），否则 D′ 的有效期亦约 **10–15 年**。
→ 因此改用期限表述：**D 层（含 D 与 D′）应读作"一个 10–15 年的撷取窗口"，而不是"一条永久边疆"。** 概率带 0.30–0.55 与内部分配（D 0.08–0.18／D′ 0.25–0.45）维持不变。

### 声明5｜方法论限制，本卡接受且不把规则升为已验证（claim_type: interpretation）
IT2 确认"可接管性"规则在地中海成立：英国**留马耳他**（制度简单、可军港化、无议会）而**拒西西里**（150 万人口＋男爵议会＋巴勒莫-墨西拿内斗）——与本卡的多巴哥 vs 圣多明各同判据。
**但 IT2 同时指出西西里案的官方理由也是正统与盟约。** 加上本卡 E13 已记的 1809 圣多明各案：
> **"可接管性"解释与"正统／盟约约束"解释在多个案例上是观察等价的（observationally equivalent）。**
本卡无法用行为证据区分二者，**并列保留**，不将 §22-④ 的规则升为已验证。可区分它们的只有**动机文书**（E13）。

### 新增改判证据
- **E16**：若取得 1809–1821 年西属圣多明各东部的**逐年财政与驻军数**，可直接检验"十二年期限"；若崩溃主因是 1820 年西班牙本土革命（即宗主国因素）而非当地财政空洞，期限命题须改写为"依赖宗主国稳定"。
- **E17**：若找到法方任何一份**为海地客户政权设计社会基盘的方案**（如向海地军官团或有色精英提供其现政权给不了的东西），则"B 被 C 支配"不再成立，B 层须上调。现有证据反向（1814 马卢埃方案的两项出价均低于对方已有之物）。
