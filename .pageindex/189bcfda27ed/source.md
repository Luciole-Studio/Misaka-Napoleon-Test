# R2数据与模型预先口径

目的：定界法国政策导致的庄园现金损失，不估计史实因果回归；不将条件区间当置信区间/后验概率。源已存盘，读取范围见notes。历史量的季调=无(annual，不适用)；币种、名义/实物、基年逐行列出；读取版本冻结于2026-09-23。本模型不用时间序列回归、不跑ADF或回测，不为方法装饰追加检验。

1. R2_series.csv长表：kind=observation_secondary（转引/低层辅助也分quality）, estimate_author, derived, missing, assumption, scenario。1803–15纸币年均辅助表与若干流通量；全国外贸未得年留空；彼堡/敖德萨值币种不明禁合计；仅单位明确指标换算。1810改革收入125→275是预算/作者口径，577是纸币债并非银币债。
2. 封锁账以无封锁同季节/同战争状态庄园现金毛收入=100。export_share=e，出口中英国依赖b（依据Crosby彼堡1/2–2/3和Davey分品61–91%，总体敏感取.50–.75）。n为经中立船继续进入原英国市场的份额；r为被堵部分的大陆替代份额；p为该部分替代/中立销售对原净产地价。英国依赖部分保留g=p*(n+(1-n)*r)。全庄园毛收入损失L=e*b*(1-g)。未暴露收入不变；没有将p作为全出口价格或进口通胀。默认无法即减的债息/成本占原收入d=.25–.50，剩余自由现金流损失=L/(1-d)。超过100即需减成本/新增债/违约，本次参数不触。全现金并非农民生存总产出。
3. 出口导向庄园e=.30–.65；内地庄园e=.03–.15。均是假设包络，不是贵族样本均值。S2 n=.70–.95,r=.10–.30,p=.90–1.00；S3 n=.15–.40,r=.10–.35,p=.65–.85。Crosby1809–11质证支持S2漏出显著，未证成n=.70实际普查；S3人为收紧，并不假装拿破仑能实际堵住全部通道。两个分支以端点全组合评估，无均匀概率假设。S2主表只限仍有形式英贸限制、靠中立/许可分支；完全合法直贸时n=1,p=1,L=0。内地表不含国内价格溢出，不能当全部福利损失。价格上行可能使S2部分人获益，主表保守不计；附g=1.05敏感度。
4. 七成反证：分别设总体等效销售恢复.70/.90,不替代价格贸易条件；计算e*(1-g)做压力探针。此探针对象为全部出口，因此不同于上述b渠道，不可混加。
5. 法国替代量：Davey1806 hemp英61/法2.4/西葡7/荷德等15.9/美国13.7；原表未明份额按数量或金额，计算额外假设同商品各目的地近似同价、份额可映为量；以Crosby约6万原书tons麻出口量仅作跨年尺度换算，不统一为公吨、不标1806精确观察；法基量1440原书tons，英36600原书tons，大陆15180原书tons(法+西葡+荷德等)，英份额/法=25.4167倍。法国直接吸收全英量需总市场26.4167倍；大陆若替全英则3.4111倍原基量。并不忽略荷德转口英国，故该大陆容量是偏宽的基准尺。另文采购包的10–35%以全部旧英国市场为分母，主模型r则以被堵而未由中立船保留部分为分母，两者不混称同一比例。
6. S5 1848人口与产出：人口只做Rashin表6同统计比较区（不含波兰/芬兰）的1811底43.785m、年增.6–.9%的规划包络；不因未来俄波/芬/外高加索征服另加人口。该比较区不严格等同当年疆界，底表对部分后来区域回列，另有登记漏误。真实人均产出改变量没有可校准面板，工业与市场化产出给方向/时间窗，不伪造GDP。可选铁路/自由港均为制度工程，不自动继承史实年份。
7. 政治压力只用0–4有序行为区间：0常态；1请愿游说；2减遵守/关税与信贷救助；3皇帝必须改政或重组核心人事；4组织化宫廷强制/战争支持。非等距、非概率，不能简单平均。区间从经济利益、制度入口与安全风险共同判断，不用L硬阈值决定政变。
